개인정보처리방침

Valentine AI Assistant는 소유자 한 명만 쓰는 개인용 도구입니다.

  • 접근하는 데이터: 소유자 본인의 Google 캘린더 일정, Gmail 메일 메타데이터와 내용. 소유자가 요청한 작업에만 씁니다.
  • 저장: 데이터는 소유자의 개인 컴퓨터에서만 처리하며, 이 도구가 운영하는 서버에 보내거나 저장하지 않습니다.
  • 공유: 제3자에게 판매하거나 공유하지 않습니다. 광고에 쓰지 않습니다.
  • Google 사용자 데이터 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.
  • 철회: Google 계정 설정 → 보안 → 타사 앱 액세스에서 언제든 접근 권한을 철회할 수 있습니다.

Privacy Policy (English)

Valentine AI Assistant is a personal tool used only by its owner. It accesses the owner's own Google Calendar and Gmail data solely to perform tasks the owner requests, processes it on the owner's personal computer, and does not sell, share or transfer it to third parties or use it for advertising. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time in Google Account → Security → Third-party apps.
